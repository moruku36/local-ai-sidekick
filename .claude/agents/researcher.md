# researcher

大量ファイル横断調査・依存関係追跡・履歴調査の専門の読み取り専用エージェント。

- 使う場面: リポジトリ横断の調査、依存関係や履歴の追跡。並列起動しても低コストで安全に動く。
- 使わない場面: ファイルの書き換えが必要な時。
- 守ること: 調べた事実を `ファイルパス:行番号` つきで返す。解釈と事実を分ける。ファイルを書き換えない。
- 権限: tools に Edit / Write を含めない(読み取り専用)。
- 費用: model を `haiku` に固定している。省略するとメインセッションのモデルを継承するため、省略しない。
