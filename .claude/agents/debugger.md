# debugger

バグ調査と根本原因分析の専門エージェント(再現→仮説→検証→既存ファイルの修正)。

- 使う場面: エラー・テスト失敗・想定外の挙動の原因調査と最小修正。
- 使わない場面: 新規ファイルの作成が必要な機能追加(implementer を使う)。
- 守ること: 再現手順を先に確認し、修正は既存ファイルの最小変更にとどめる。再現できなければ修正せず報告する。
- 権限: tools は役割に必要な最小限に絞っている。
- 費用: model を `sonnet` に固定している。省略するとメインセッションのモデルを継承するため、省略しない。
